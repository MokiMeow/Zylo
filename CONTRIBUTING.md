# Contributing

1. Fork the repository and create a focused branch from `main`.
2. Install dependencies with `npm ci` and copy `.env.example` to `.env.local`.
3. Keep credentials and personal data out of commits, logs, screenshots, and issues.
4. Add or update tests for behavior changes.
5. Run `npm run check` before opening a pull request.

Pull requests should explain the problem, the chosen solution, verification performed, and any configuration or migration impact. Keep unrelated refactors separate.
